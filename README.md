# Face Recognition using CNN

## Overview
This project implements a Face Recognition system using a Convolutional Neural Network (CNN) with TensorFlow and Keras. The model is trained on the Olivetti Faces dataset and can classify different individuals based on facial images.

## Dataset
- Olivetti Faces Dataset
- 400 grayscale face images
- 40 individuals
- 10 images per individual
- Image size: 64 × 64 pixels

## Technologies Used
- Python
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- TensorFlow
- Keras
- Google Colab

## Features
- Data preprocessing
- CNN model training
- Model evaluation
- Confusion matrix
- Classification report
- Accuracy visualization

1. Clone the repository


2. Install the required libraries

```bash

```

3. Open the notebook

```bash
jupyter notebook FaceRecognition.ipynb
```

## Results

The CNN model successfully learns facial features from the Olivetti Faces dataset and predicts the correct person with high accuracy.
